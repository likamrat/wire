## Contributor references

Read the relevant contract before changing its behavior; these references are
not additional setup steps.

| Change | Contract |
| --- | --- |
| Shared screen hierarchy, typography, layout or motion | [Product design](design.md) |
| A screen's controls, reading order or navigation behavior | [Interaction design](interaction-design.md) |
| Report membership, formats, privacy or frozen facts | [Report contract](report-contract.md) |
| Search matching, highlights, receipts or Open | [Local text Search](live-search.md) |
| Searchable content, admission or saved-file extraction | [Authorized search corpus](search-corpus.md) |
| Access, collection admission, withdrawal or uncertain operations | [Runtime access](runtime-access.md) |

Contributors using Copilot can choose a [WIRE development skill](../.github/skills/README.md)
for the task. The skills guide the work and point to these contracts; they are
optional and grant no additional permissions.
