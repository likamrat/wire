# Security

## Report a vulnerability

Email suspected WIRE vulnerabilities to [likamrat@microsoft.com](mailto:likamrat@microsoft.com).
Do not post vulnerability details, credentials or private history in GitHub issues.

Include what you can safely share:

- The affected WIRE commit or version, operating system and Node version.
- Steps to reproduce using invented data, with a minimal example if possible.
- The expected behavior, what happened and the potential security impact.

Coordinate disclosure with the maintainer before publishing technical details.

## Test without exposing data

Use an isolated WIRE data directory and sources you own or have permission to test.
Remove credentials, personal prompts, reports and browser-profile data from
attachments. Local masking can miss confidential information, so review examples
before sending them.
